# Jenkins Uwagbai portfolio (v2)

Next.js (App Router) + Tailwind CSS 3 + TypeScript + Framer Motion.

## Run
    npm install
    npm run dev

## Update content
All copy lives in `lib/data.ts` (experience, projects, skills, links). No component edits needed.

## Assets to copy in
- `public/Jenkins_Uwagbai_CV.pdf` (your new CV, same filename as the old one)
- `public/projects/coconut.png`, `rally.png`, `livenow.png` (your existing screenshots).
  Missing images fall back to a colour tile, so nothing breaks.

## Deploy
Push to the repo connected to Netlify/Vercel. No env vars required.
